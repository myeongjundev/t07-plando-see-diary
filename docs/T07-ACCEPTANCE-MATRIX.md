# T07 공식 통과 기준 매트릭스

상태: **2026-09-03에 `docs/source/T07-OFFICIAL-ASSIGNMENT.md`에서 고정. 기준 68개.**

**통과시키려고 기대값을 낮추거나 지우거나 고쳐 쓰지 않는다.** T06에서 지킨 규칙 그대로다.

## 열이 세 가지인 이유

| 열 | 성질 |
| --- | --- |
| **통과 기준** | **얼지 않는다.** 과제 원문 문장을 그대로 옮겼다. 번역하거나 줄이지 않는다 — 옮기는 과정에서 뜻이 흔들리는 것이 가장 흔한 사고다 |
| **확인하는 행동** | 그 기준을 눈에 보이게 만드는 최소 행동. 구현하며 더 정확해질 수 있다 |
| **자동 검사 · 증거** | **아직 전부 계획이다.** 구현 전이라 이 이름의 검사는 존재하지 않는다 |

`자동 검사 · 증거` 칸의 갈래:

- **자동** — `backend/tests`의 pytest. 돌리면 재현된다
- **증거** — `backend/scripts/collect_auth_evidence.py`가 찍는 `docs/T07-EVIDENCE/*.md`
- **배포본** — 공개 앱에서 직접 본 것. 자동화할 수 없다
- **스캔** — `backend/scripts/audit_secrets.py`
- **제출문** — 문서에 적혀 있는지로만 판정된다. 검사할 코드가 없다

### 이 문서가 원문에서 흘러가는 것을 막는 장치

`backend/tests/acceptance/test_t07_matrix_matches_assignment.py` — **지금 돌고 있다.**
T06의 `tools/generate_verification.py`가 하던 일을 검사 쪽으로 옮긴 것이다.

| 검사 | 무엇을 막나 | 지금 |
| --- | --- | --- |
| `test_matrix_covers_every_official_criterion` | 기준이 조용히 빠지거나, 원문에 없는 것이 끼어드는 것 | ✅ 돈다 |
| `test_matrix_quotes_each_criterion_verbatim` | 옮기다 문구가 흔들리는 것. **글자 단위로** 대조한다 | ✅ 돈다 |
| `test_planned_test_names_exist_once_they_are_written` | 아래 표의 검사 이름과 실제 코드가 어긋나는 것 | ⏸ 대기 |

셋째 검사는 T07 검사가 하나도 없는 지금 켜 두면 첫날부터 빨개져서 무시당한다. 그래서
**이름 붙은 검사가 하나라도 생기는 순간 스스로 켜진다.**

문구 대조가 실제로 무는지 확인했다(2026-09-03): C96을 「로그아웃할 수 있다」에서
「로그아웃이 대체로 된다」로 바꿔 보니 그 한 줄을 집어내며 떨어졌다.

관련 설계: `docs/T07-ARCHITECTURE.md` · 증거 파일 목록은 그 문서 10절.
