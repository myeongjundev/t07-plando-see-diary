## 9. PPT와 아키텍처 PDF 확정

현재 파일:

- PDF는 `tools/build_architecture_pdf.py`가 그린다. 저장소 안에서 다시 만들 수 있고,
  실제로 배송본과 바이트 단위로 같은 결과가 나오는 것을 확인했다(생성 시각·문서 ID 제외).
